# マイツール置き場（GitHub Pages）

HTMLツールを固定URLで使うための一式です。データは各端末のブラウザ内（localStorage）にだけ保存され、このリポジトリには入りません。

## 入っているファイル

| ファイル | 内容 |
|---|---|
| index.html | 入口ページ（リンク集） |
| swim-import.html | 競泳 結果の取り込み（iPhone版） |
| swim-best-lap.html | 競泳 自己ベスト・試合ラップ表（PC版） |
| kakeibo.html | 家計簿 |

## 公開の手順（10分ほど）

1. GitHubにログインし、新しいリポジトリを作る
   - 名前は例：`my-tools`（半角英数字）
   - **Public** を選ぶ（無料プランのGitHub Pagesは公開リポジトリが前提）
2. リポジトリの画面で「Add file」→「Upload files」を選び、このフォルダの4ファイルをアップロードして「Commit changes」
3. リポジトリの「Settings」→ 左メニューの「Pages」
4. 「Build and deployment」の Branch を **main / (root)** にして「Save」
5. 数分待つと、Pagesの画面に公開URLが表示される
   - 形：`https://（ユーザー名）.github.io/my-tools/`
6. iPhoneのSafariで公開URLを開き、使うツールごとに「共有」→「ホーム画面に追加」

## データの移し替え（大事）

- 保存データはURLごとに分かれます。今まで一時リンクで開いていた分は、新しいURLでは見えません。
- 競泳：PC版（今のファイル）でJSONを書き出し → 新しい場所のiPhone版「設定」タブで読み込む。PC版も新しいURLで開けば、そちらのデータも引き継げます（同じURLで開き直す前に、旧ファイルでJSONバックアップを取ってください）
- 家計簿：旧リンク側でJSONバックアップを書き出し → 新しい場所で読み込む

## 更新のしかた

- ツールの新しい版ができたら、リポジトリで同じファイル名のままアップロードし直すだけです（上書きされます）。URLは変わらないので、保存データはそのまま使えます。
- ファイル名は変えないでください。名前が変わると別のURLになり、データが見えなくなります。
